# وصال — مشروع الزوار

هذه نسخة الزوار المنفصلة من وصال. يفتح الزائر `/` فتظهر محادثته الخاصة مباشرة دون حساب. يستطيع إرسال النص والصور والفيديو والتسجيلات الصوتية، ومشاهدة ردود المدير وحالاته وصورته ومعلوماته للقراءة فقط.

لا يوجد هنا مسار `/admin` أو تسجيل دخول للمدير. مشروع المدير والخادم محفوظ في [whatsapp](https://github.com/saddamsaggar400-oss/whatsapp).

## الاتصال بالمدير

تتصل هذه الواجهة بالخادم المشترك الحالي:

`https://wisal-direct-20261106.cottonvine2.chatgpt.site`

ولوحة المدير هي:

`https://wisal-direct-20261106.cottonvine2.chatgpt.site/admin`

لا تنشئ قاعدة بيانات جديدة لهذا المشروع. جميع الرسائل والمرفقات والقراءات والحالات محفوظة في D1 وR2 لدى الخادم المشترك، فتظهر رسالة الزائر في قائمة المدير، ويعود رده إلى محادثة الزائر نفسها. المصدر في GitHub وحده ليس استضافة ويب؛ النسخة الجديدة تحتاج نشر مشروع Node.js لتُفتح من نطاق مستقل. رابط الزوار المنشور سابقًا ما زال يعمل على `/` في الخادم المشترك.

## التشغيل

استخدم Node.js 22.13 أو أحدث، ويفضل Node.js 24:

```bash
npm ci
npm run dev
```

ثم افتح `http://127.0.0.1:3000/`.

للبناء والتشغيل:

```bash
npm run build
npm start
```

يحتاج النشر إلى تشغيل خادم Next.js يدعم الاستجابات المتدفقة للرسائل اللحظية ورفع الملفات. ليس هذا مشروع GitHub Pages أو تصدير HTML ثابتًا. لا تحتاج إلى إعداد حساب مدير أو إضافة مفاتيح قاعدة بيانات في مستودع الزوار.

يمكن تخصيص عنوان الخادم من متغير البيئة `WISAL_BACKEND_URL`، بقيمة أصل HTTPS فقط دون مسار، مثل القيمة في `.env.example`. القيمة الافتراضية متصلة بالفعل بالخادم الحالي. يظل متغير البيئة في الخادم ولا يقبل الزائر تغييره من طلب API.

## الجلسة والصلاحيات

- تُحفظ هوية الزائر في ملف ارتباط HttpOnly وSameSite، مع Secure عند استخدام HTTPS. تعود المحادثة عند الرجوع من المتصفح والنطاق نفسيهما. النطاق الجديد له جلسة خاصة ولا ينسخ ملفات ارتباط نطاق آخر تلقائيًا؛ محادثات المدير الموجودة تبقى محفوظة.
- يمر الطلب عبر بوابة في خادم الزوار إلى خادم وصال. تُنقل هوية الضيف فقط، وتُحذف أي ملفات ارتباط أو ترويسات خاصة بالمدير. لا يعتمد الاتصال على ملفات ارتباط خارجية أو السماح بـCORS.
- تُرفض مسارات دخول المدير وطلب بيانات المستخدمين وتعديل حسابه ونشر أو حذف حالاته. وتُرفض طلبات الكتابة من مواقع خارجية قبل تمريرها.
- يتحقق الخادم المركزي من عضوية المحادثة عند كل قراءة أو إرسال أو تحميل مرفق. اختيار معرّف محادثة زائر آخر لا يمنح الوصول إليها.
- تُمرّر قناة SSE دون جمع الرسائل أو تخزينها مؤقتًا. لا تسجل بوابة الزوار استلامًا أو قراءة من تلقاء نفسها؛ تبقى الإقرارات مرتبطة بالجلسة المستلمة والرسائل المعروضة.

## التحقق

```bash
npm test
npm run typecheck
npm run build
```

تغطي الاختبارات نقل هوية الضيف وحدها، ومنع طلبات المدير، وحماية مصدر الطلب، واستمرار الجلسة، وتمرير الرسائل وإقرارات الاستلام والقراءة والمرفقات والفيديو، ووصول الأحداث اللحظية دون انتظار إغلاق القناة. صلاحيات المحادثات وتخزين الرسائل وإقراراتها تُنفذ في الخادم المشترك الذي اختُبر في مشروع المدير.
